# Nexus Pad Releases

This public repository contains signed installers and update metadata for **Nexus Pad**. Source code and issue tracking live in the private application repository.

## Downloads

Download the newest stable build from [Releases](https://github.com/CyKrome-Nexus/Nexus-Pad-Release/releases/latest).

| Platform | Installer |
| --- | --- |
| macOS (Apple Silicon) | `.dmg` — `aarch64` |
| macOS (Intel) | `.dmg` — `x64` |
| Windows | `.msi` or `-setup.exe` |
| Linux | `.AppImage`, `.deb`, or `.rpm` |

Installed copies verify every self-update against the signing key embedded in the application. This repository intentionally contains release assets only.
